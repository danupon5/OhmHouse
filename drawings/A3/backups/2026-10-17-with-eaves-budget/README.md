## ฐานประมาณการชายคา

ผู้ใช้ยืนยันฝ้าเอียงตามแนวจั่ว รุ่นเฌอร่า 60×120 ซม. หนา 4 มม. ราคา 58 บาท/แผ่น พื้นที่ 43.28 ตร.ม. อ้างจากตารางในแบบ construction_drawings.html บน GitHub เดิม ซึ่งยังไม่ยืนยันว่าเป็นพื้นที่ราบหรือผิวจริง และยังไม่ตรวจพื้นที่ซ้ำกับฝ้าลานล่าสุด

เพื่อเผื่องบ: สมมติช่วงยื่น 1 ม. แผ่นวาง 120 ซม. จากผนังออกชายคา / 60 ซม. ตามแนวลาด ใช้ฐาน ceil(43.28/(1×0.6)) = 73 แผ่น เพิ่มตัวประกอบสำรอง 1/cos(28.438°) ≈1.137 สำหรับความไม่แน่นอนของแนวลาด/มุม ไม่ใช่การอ้างว่าเป็นการแปลงพื้นที่จริง ได้ ceil((43.28/0.6)×1.137)=83 แผ่น เผื่อตัดเสีย 10%=9 รวมเผื่องบ92แผ่น/5,336บาท ตัวประกอบมุมอ้างอิง scene-v413.json rseg_lr_symcenter เพื่อใช้เป็นสำรองเชิงงบเท่านั้น

**92 แผ่นไม่ใช่ยอดสั่งซื้อที่ตรวจจากผังตัดชายคาครบ ต้องตรวจระยะช่วงยื่น มุม และพื้นที่ทับลานก่อนสั่งซื้อจริง** หากยื่นเกิน1.20ม.ต้องตรวจวิธีต่อเพิ่ม ไม่ใช้เศษฝ้าลายร่องทดแทนแผ่นมีรู

## ผังยืนยันสามโซนเดิม

ภายใน94.4202ตร.ม. ใช้ยิปซัมธรรมดา37แผ่น/53ชิ้น เริ่มเต็มแผ่นมุมขวาล่างห้องนั่งเล่นและใช้เศษร่วมกับห้องอื่น ไม่บวก21แผ่นทำเฉพาะห้องนั่งเล่นซ้ำ ห้องน้ำ11.76ตร.ม.ใช้5แผ่น/6ชิ้น ราคา215บาทต่อแผ่นตามยืนยัน ลาน4.03×8.94ม.วางขวางใช้15แผ่น/16ชิ้น แผ่น15ใช้จริง ยอดสามโซนรวมเผื่อ63แผ่น/12,048บาท

ราคาเฉพาะแผ่น ไม่รวมโครง อุปกรณ์ สี ค่าแรงและขนส่ง ราคา134บาทยิปซัมธรรมดาสมมติได้โปรทุกแผ่น วัดสุทธิและจัดโครงรองรับตามระบบผู้ผลิตก่อนติดตั้ง
