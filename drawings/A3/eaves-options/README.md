## การแก้ไขโซน

ขอบหลังคาขวาตรงต่อเนื่อง แถบฝ้ามีรูคงความกว้างที่ริมขอบ พื้นที่ว่างเหนือห้องเก็บของ(ซักล้าง)และใต้ห้องเก็บของ(ส่วนเว้า)เป็นSmartboardเรียบ ไม่รวมในฝ้ามีรู หักกรอบเพิงลานออกทั้งสองแบบ ภายในใช้ผังเริ่มเต็มแผ่นมุมขวาล่างห้องนั่งเล่น และใช้เศษกับห้องอื่น ไม่บวกยอดทำเฉพาะห้องนั่งเล่น21แผ่นซ้ำ

## ฐานคำนวณและข้อจำกัด

1. ชายคาเป็นแบบสมมติเปรียบเทียบ A1ม./B0.7ม. รอบกรอบฝ้าคลุมบ้านรวมSmartboard ที่แก้ให้ด้านขวาตรง ใช้มุม25°ปีกห้องนอนและ28.438°/17.045°ห้องนั่งเล่น แยกชิ้นที่สันจั่วและแบ่งมุม หักกรอบเพิง4.03×9.04ม.จากฝ้าลานเดิม พิกัดกรอบตัด[1.47,5,5.5,14.04]เมตร ไม่ใช่ผลวัดขอบหลังคาGLBล่าสุด ต้องตรวจว่าความกว้างที่เลือกอยู่ใต้หลังคาเดิมได้ ไม่มีราคางานขยายโครงหลังคา
2. ทุกชิ้นฝ้ามีรูตรวจแล้วไม่ทับกรอบเพิงหรือโซนSmartboard รูปหลังคา/ชิ้นตัดเป็นแบบวางแผน ไม่ใช่shop drawingอนุมัติติดตั้ง
3. Smartboardผู้ใช้เลือก60×120ซม. ความหนาและราคายังไม่ยืนยัน พื้นที่สุทธิ8.65+6.05=14.70ตร.ม.อ้างREADME-v413.mdบนGitHub ผังตัดใช้กรอบประมาณ1.79×4.83และ1.79×3.38ม.ให้พื้นที่14.6959ตร.ม. ยังไม่ใช่ระยะสำรวจรายขอบ แผ่นเรียบหมุนตัดใช้เศษร่วมได้ หลีกเลี่ยงขอบ3ซม. ชิ้นตามแนวแถวเล็กสุดในผัง18ซม.
4. การใช้เศษเผื่อใบตัด3มม. ตรวจชิ้นอยู่ในแผ่นและไม่ซ้อนกัน กริดเพื่อถอดวัสดุ ไม่ใช่ผังโครง ต้องวัดสุทธิและจัดโครงรองรับทุกขอบตามคู่มือ
5. ราคายิปซัมธรรมดา134บาทสมมติได้โปรทุกแผ่น ราคาเฉพาะแผ่น ไม่รวมโครง อุปกรณ์ สี ค่าแรงและขนส่ง
