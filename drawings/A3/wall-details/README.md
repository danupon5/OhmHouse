# OhmHouse — ระยะผนังทุกจุด A3

WD-01 เป็นผังดัชนี 1:75; WD-02 ถึง WD-22 ครบผนัง WL01–WL21 ผังขยายใช้ 1:25 หรือ 1:50 ตามที่ระบุ รูปด้านคลี่ใช้ 1:50 พิมพ์ A3 แนวนอน 420×297 มม. ที่ 100% และตรวจเส้น 100 มม. ท้ายหน้า

จุดอ้างอิง 182 จุด ครอบคลุมปลายแกน ขอบช่องเปิด จุดตัดผนัง ผิวผนังตามความหนาในไฟล์ ศูนย์กลางและขอบฉายเสาตามแนวผนัง ตารางแสดงระยะจาก A และระยะจากจุดก่อนหน้า มีรูปด้านคลี่และระดับช่องเปิดครบ 27 จุด

ระยะปัดที่ 0.001 ม. จุดที่ปัดได้ค่าเดียวกันรวมเป็นแถวเดียว ระยะย่อยรวมตรง A–B ครบ 21 แนว จุดนอก A–B แสดงแยก ไม่ใช้รวม บางช่วงอยู่ภายในผนังหรือเสา ไม่ใช่ช่องว่างสุทธิ ผิวผนังยังไม่รวมฉาบ/วัสดุกรุที่ไม่ระบุในแบบ D09R เกิน B ของ WL17 0.010 ม. ต้องตรวจแก้ก่อนผลิต
